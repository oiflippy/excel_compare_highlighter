# Excel 表格对比高亮工具

一个轻量 Windows 桌面软件，用于按规则给 Excel 表 B 填色：从表 A（可为单个文件或整个文件夹）读取“查找项”和“指定项”，再到表 B 的“查找项”列中匹配，命中后按 A 表指定项对应的颜色规则给 B 表整行或指定列填色。

## 功能

- 选择表 A 来源，可选单个 Excel 文件或整个文件夹；选择表 B 作为待填色文件。
- 表 A 选择“指定项列”和“查找项列”；表 B 选择“查找项列”。
- 可指定 A 的匹配起止行、B 的查找起止行；留空时默认从表头下一行到末尾。
- 可指定 B 的填色开始列和结束列；留空时默认整行填色。
- 可配置指定项颜色规则，例如 `A=#FFF2CC;B=#C6EFCE`；没有写规则的指定项使用默认颜色。
- 快速预览命中行，确认列选择是否正确。
- 将表 B 命中行整行填充指定颜色，并另存为新文件，不覆盖原文件。
- 表 A 文件夹模式会提前检查所有文件是否存在同名 Sheet，避免跑到一半才报错。
- 表 A 文件夹模式会校验所有文件的表头/列结构一致；预览选择时显示排序后的第一个文件作为格式模板。
- 自动记住成功导出的配置；遇到表头相似的新表，会自动套用之前的列和颜色配置。
- 大表处理使用流式读取，界面处理任务放到后台线程，并显示分阶段状态。

## 快速运行

1. 安装 Python 3.10 或更高版本。
2. 在当前目录打开命令行，安装依赖：

   ```powershell
   python -m pip install -r requirements.txt
   ```

3. 双击 `run.bat`，或运行：

   ```powershell
   python app.py
   ```

## 打包成 Windows EXE

双击 `build_exe.bat`，或运行：

```powershell
python -m pip install -r requirements.txt
python -m PyInstaller --noconfirm --clean --windowed --name "ExcelCompareHighlighter" app.py
```

打包结果在：

```text
dist\ExcelCompareHighlighter\ExcelCompareHighlighter.exe
```

## 使用步骤

1. 点击“浏览...”选择表 A（文件或文件夹）和表 B（待填色文件）。
2. 选择两个表各自的 Sheet，填写表头行，默认第 1 行。
3. 分别点击 A/B 的“选列”，程序会打开真实表格预览；在表格里点击任意单元格即可选中它所在的列。
4. 在表 A 选“指定项列”和“查找项列”，在表 B 选“查找项列”；不需要靠表头列表猜列。
5. 点击 A 数据行、B 查找行、填色列旁边的“预览选择”，在真实表格里点选起止行或起止列。
6. 点击“配置颜色”，从 A 指定项列读取真实值，为需要填色的指定项选择颜色；没选颜色的指定项保持原色。
7. 如果修改了 Sheet 或表头行，可点击“刷新 A 表”或“刷新 B 表”重新读取。
8. 点击“预览”，确认 B 表命中行和填色颜色是否符合预期。
9. 点击“生成高亮文件”，保存结果。

## 匹配不到时先检查

- 表 A 查找项列和表 B 查找项列是否选了同一类字段，例如都选“身份证号”、都选“岗位编号”，不要一边选姓名一边选编号。
- 表 A 指定项列是否选对；颜色规则匹配的是这一列的值。
- 行范围是否覆盖真实数据；如果表头不是第 1 行，要先改表头行，再读取列名。
- B 的查找列中如果有值但 A 中没有对应值，该行不会标色，这是预期行为。
- 如果表 A 是文件夹，所有文件需要有同名 Sheet；程序会提前列出不符合的文件。
- 程序会自动去掉首尾空格、合并中间连续空白，并默认不区分大小写。
- 如果 Excel 中看起来一样但仍匹配不到，检查是否存在全角/半角差异、隐藏字符、数字和文本格式差异。

## 配置自动加载

软件会把成功导出的配置保存到 Windows 用户目录：

```text
%APPDATA%\Excel Compare Highlighter\profiles.json
```

下次选择相似表头的两个表时，会自动套用之前的匹配列、颜色和大小写设置。

## 兼容性说明

- 支持 Office 2007 以后常见的 OpenXML Excel 格式。
- 不支持旧版 `.xls`，如果需要处理，请先用 Excel 或 WPS 另存为 `.xlsx`。
- `.xlsm` 会尽量保留宏结构，但建议导出后自行打开检查宏和格式。
- 极大文件导出时需要足够内存，因为写入颜色必须加载目标工作簿。
